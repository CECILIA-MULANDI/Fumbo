# VeilDraw

Confidential no-loss prize savings on FHEVM.

Deposits, balances, and winnings stay encrypted end-to-end using the Zama Protocol. Sponsors fund periodic prize draws; one winner is chosen at random, weighted by encrypted deposit size.

Built for the Zama Developer Program, Mainnet Season 4 (Bounty Track).

## Status

Early development. Contract design and architecture in progress.
